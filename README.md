# Skin Cancer Detection using Deep Learning

This project uses deep learning with EfficientNet to classify skin images as benign or malignant.

## Features
- Transfer Learning (EfficientNet)
- Streamlit UI
- FastAPI backend
- Image preprocessing

## Tech Stack
Python, TensorFlow, Keras, Streamlit, FastAPI

## How to Run
1. Install dependencies
2. Run train.py
3. Run ui.py using Streamlit
